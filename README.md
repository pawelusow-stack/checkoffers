# Мониторинг позиций на витринах МФО

Админ-панель на Streamlit для отслеживания позиций офферов на витринах.

## Быстрый старт (локально)

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Деплой на хостинг (для нескольких пользователей)

### Вариант 1. Streamlit Community Cloud (рекомендуется, бесплатно)

Самый простой способ именно для Streamlit.

1. Залейте проект в GitHub-репозиторий.
2. Зайдите на https://share.streamlit.io
3. Нажмите **New app** → выберите репозиторий и файл `app.py`.
4. (Опционально) Защита паролем:
   - В настройках приложения → **Secrets** добавьте:
     ```toml
     APP_PASSWORD = "ваш_пароль"
     ```
   - Или задайте переменную окружения `APP_PASSWORD`.

После деплоя получите публичную ссылку вида `https://your-app.streamlit.app`.

### Вариант 2. Render.com

1. Залейте код в GitHub.
2. На Render создайте **Web Service**.
3. Настройки:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`
4. Добавьте переменную окружения `APP_PASSWORD` если нужна защита.

### Вариант 3. Railway / Fly.io / любой VPS

Аналогично Render: установите зависимости и запустите:

```bash
streamlit run app.py --server.port $PORT --server.address 0.0.0.0
```

## Защита паролем

Если задана переменная окружения `APP_PASSWORD`, при входе будет запрошен пароль.  
Если переменная не задана — панель открыта для всех.

## Как добавить витрину

Откройте `app.py`, найдите список `SOURCES` и добавьте новый словарь с селекторами.  
После изменения перезапустите / передеплойте приложение.

## Возможности

- Выбор витрин
- Фильтр по кредитору (поиск позиции конкурента)
- Таблица с подсветкой позиций (топ-3 / топ-10)
- Экспорт в CSV и Excel
- Простая авторизация по паролю
